# Aether fork notes

Aether is maintained by `justinx2022` and is based on the SkyStream source project:

- Upstream project: https://github.com/akashdh11/skystream
- Aether project: https://github.com/justinx2022/aether
- Upstream license: GNU General Public License v3.0 only (`LICENSE`)

This codebase has been rebranded and adapted for Aether. Platform app IDs, package names, updater/release targets, and Aether-specific playback behavior are maintained here. The `SkyStreamProvider` type and the `skystream://` repository-link scheme remain as compatibility interfaces for existing extensions and saved repository links; they do not identify the Aether app or its release channel.
